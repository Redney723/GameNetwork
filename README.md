- [ ] 서버 및 테스트 클라이언트 코드 분석

- [ ] 확인된 결함 및 수정 내용을 보고서에 정리

## 4. Part B — 서버 성능 측정 (25점)

- [ ] 개인 PC 환경 및 수정 전 성능 측정
- [ ] 동시 접속에 따른 성능 저하 구간 확인

- [ ] 검증 결과 및 증거자료 정리

## 6. Part D — 작업 과정 기록 (20점)

- [ ] 실제 작업에 따른 Git 커밋 8개 이상 기록

- [ ] GitHub 저장소 주소 및 Git 로그 확보
